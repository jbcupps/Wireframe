Edit geometry & model JSON

Use declarative data only. Integer or string vertices, up to five vertices per simplex. No Python code is evaluated. Limits of this workflow

Facet incidence is necessary in the applicable setting, but it does not establish manifold neighborhoods. Exact mod-2 homology does not classify manifolds or prove orientability. Smoothness, Pin structure, causality, stability and particle identity are not established. A passing report can still hide an untested singularity. Operations involving w do not imply Lorentzian isometries or physical time evolution.
