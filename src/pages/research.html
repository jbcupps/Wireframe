CSV capacity and format

Use UTF-8 CSV with the explorer headers. Imports support 30,000,000 operations across all rows, 64 columns, 64,000,000 cells and up to 1 MB per CSV record. Each piece can contain up to 4,096 operations. Long sequences may require a one-row display. Imported positions are separate from source row numbers and generated ranks. CSV import supplies candidate descriptions; geometry assessment and notebook limits are separate.

Order and repetitions are preserved. Opposite signs do not cancel. Bounded triples use C-fastest Cartesian ordering; unbounded triples use nested Cantor pairing. Row ranks are not candidate IDs. There is no theoretical repetition limit; this session accepts 4,096 operations per piece. Symbolic CSV rows supply no geometry or assessment evidence.

Edit geometry & model JSON

Use declarative data only. Integer or string vertices, up to five vertices per simplex. No Python code is evaluated. Use joining.target = closed or exterior_interface; declare expected_exterior_faces for the latter. Model fields record underlying space, operations, composition, directions, equivalence rules, differentiability, metric, time and physical mapping.

Limits of this workflow {{ help_tip('limits', 'What remains unresolved', 'The current checks do not establish smoothness, dynamical stability, causality, Pin structure or particle identity. More explicit models and validation methods are needed.', 'limits') }}

Facet incidence is necessary in the applicable setting, but it does not establish manifold neighborhoods. Exact mod-2 homology does not classify manifolds or prove orientability.
