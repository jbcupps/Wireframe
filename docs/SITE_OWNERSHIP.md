# Independent physics sites

This repository owns theories.spacetimemanifolds.com through the existing Vercel
project `wireframe` in `jim-cupps-projects`. Production deployments follow `main`.
The topology explorers and research material remain here.

The introductory landing page and projectile game now have their own repository,
[jbcupps/spacetimemanifolds](https://github.com/jbcupps/spacetimemanifolds), and their
own Vercel project, `spacetimemanifolds`, for spacetimemanifolds.com.

Other independently managed sites:

| Host | GitHub repository | Vercel project |
| --- | --- | --- |
| newtonian.spacetimemanifolds.com | jbcupps/newtonian-physics | newtonian-physics |
| relativity.spacetimemanifolds.com | jbcupps/relativity-physics | relativity-physics |
| quantum.spacetimemanifolds.com | jbcupps/quantum-physics | quantum-physics |

Each site owns its source, deployment history, environment settings and domain
assignment. Links between sites are ordinary HTTPS links; there is no shared
runtime or coordinated release requirement. DNS is managed in Squarespace.
Existing 4dnod and 4dttso hosts have separate existing configurations.
